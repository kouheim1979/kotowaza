# ことばクエスト
## 〜慣用句・ことわざ・四字熟語バトル〜

小学4年生向けに作った、ことば学習クイズゲームです。  
慣用句・ことわざ・四字熟語を、暗記だけでなくゲーム感覚で楽しく学べます。

## 概要
- 1プレイ10問、約3〜5分で遊べる学習ゲーム
- スマホ・タブレット・PCどちらでも遊べるレスポンシブデザイン
- ビルド不要。ファイル一式を置いたフォルダの `index.html` を開くと動作
- 外部API・外部ライブラリ・Webフォント不使用
- localStorage で学習記録を保存

## 対象ユーザー
- 小学4年生（および保護者・先生）
- 慣用句・ことわざ・四字熟語を楽しく学びたい人

## デザインの考え方（小学4年生向け）
- **ノートとかるた**：方眼ノートの上に、かるたの札を並べたような見た目。ことばのカードには、かるたの取り札のように最初の1文字を赤丸で入れています
- **赤ペンの丸つけ**：答えると、先生の赤ペンのように正解に ○ がつき、正解すると「はなまる」。まちがえた答えには × がつき、正しい答えも同時にわかります
- **ふりがな**：4年生でまだ習わない漢字（慣用句・四字熟語・図鑑・復習など）にふりがな。ことばには読みを表示。設定でオフにもできます
- **文字**：ことばは教科書体（Windows の UD デジタル教科書体、Mac のクレー）で表示し、ない端末では丸ゴシックで表示します
- **情報をしぼる**：タイトルはレベルと次のレベルまでの問題数、スター・図鑑・最高点だけ。クイズ中は問題の進み具合・点数・コンボだけ
- **大きなボタン**：タップするところは高さ56px以上。分かち書き（ことばの区切りにスペース）で、行の途中でことばが切れにくいようにしています
- **色の意味**：慣用句＝オレンジ、ことわざ＝緑、四字熟語＝青、ミックス＝ピンク、復習＝むらさき、きまり文句（ことばくじのみ）＝青緑
- **ことば博士**：めがねのサルの博士が案内役。「猿も木から落ちる」から、まちがえても大丈夫と伝えます
- **やさしい確認**：ブラウザの確認ダイアログではなく、画面の中で「やめる？」「消す？」を確認します
- 動きを減らす設定（OSの「視差効果を減らす」など）にしていると、アニメーションを止めます

## 主な機能
- 7画面構成
  - タイトル画面（きょうのことば・きろく）
  - モード選択画面（種類ごとの図鑑の集まりぐあいつき）
  - クイズ画面
  - 結果画面（評価スタンプ・新しく図鑑に入ったことば・まちがえたことば）
  - 言葉図鑑画面（縦書きのかるたで表示。タップで意味・説明・使い方）
  - 復習ノート画面
  - 設定画面
- 5モード
  - 慣用句
  - ことわざ
  - 四字熟語
  - ミックス
  - 復習（まちがえたことばを優先して出題）
- 3種類の問題形式をランダム出題
  - 意味を選ぶ
  - 言葉を選ぶ
  - ストーリー（場面に合うことばを選ぶ）
- 問題データ45問（慣用句15 / ことわざ15 / 四字熟語15）
- 難易度設定（ぜんぶ / かんたん / ふつう / むずかしい）
- ふりがな設定（つける / つけない）
- コンボ・ボーナス・ヒント減点・まちがいモンスターとのバトル
- 図鑑コレクション（未取得は「？」のかるた）
- 学習記録リセット（保護者向け・二段階確認。設定はそのまま残ります）
- キーボード操作：1〜4キーで回答、Enterで次へ

## 遊び方
1. タイトル画面で「スタート！」
2. バトル（モード）を選ぶ
3. 10問のクイズに回答する
4. 結果画面で正解数・評価スタンプ（たいへんよくできました／よくできました／がんばりました）・ランク（S/A/B/C）を確認
5. 図鑑で集めたことばを確認
6. 復習ノートから、まちがえたことばに再チャレンジ

## ことばくじ

タイトル画面の「ことばくじ」から、ことわざ・慣用句・四字熟語・きまり文句のかるたを引けます。種類と枚数を選べて、「おまかせ」は毎回3〜5枚です。カードを開くと意味と使い方が表示されます。「ぜんぶ ひらく」でまとめて開けます。

- `random/app.js` : 決まり文句のデータとカード表示

## GitHub Pagesで公開する方法
初心者向けに、最短手順で書いています。

1. GitHubにリポジトリを作る
2. このプロジェクトのファイルをアップロードする
3. リポジトリの **Settings** を開く
4. 左メニューの **Pages** を開く
5. **Branch** を `main` / `root` にする
6. **Save** を押す
7. 表示されたURLにアクセスする
